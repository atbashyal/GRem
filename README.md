# GRem — Ergonomic Break Reminder

**GRem** is a lightweight, non-intrusive desktop break and ergonomic reminder application built with **Kotlin Multiplatform (KMP)** and **Compose Multiplatform Desktop**.

It sits silently in your system tray and displays smooth animated break overlays to remind you to stretch, take a break, or drink water without interrupting your workflow.

---

## ✨ Features

- **📍 System Tray First**: Runs discreetly in the Windows system tray without cluttering your taskbar.
- **🖼️ Animated Break Overlay**: Displays a smooth animated WebP pop-up in the corner of your screen when it's time for a break.
- **⌨️ Focus-Safe & Non-Interruptive**: The overlay stays pinned on top (`Always On Top`) but **never steals keyboard focus** (`focusable = false`). You can keep typing in your text editor, IDE, or browser without missing a keystroke.
- **⚙️ Customizable Schedules**: Set custom break interval timers in Hours, Minutes, and Seconds via an easy-to-use Settings window.
- **⚡ Quick Tray Controls**:
  - **Show break now**: Trigger a break reminder on demand.
  - **Pause / Resume**: Easily toggle automatic break scheduling on or off.
  - **Settings**: Quick access to customize interval preferences.
- **📦 Native Installers & Binaries**: Bundled into standalone Windows executables (`.exe`), `.msi` installers, and portable application packages with custom branding (`grem.ico`).

---

## 🛠️ Architecture

GRem is built following modern Kotlin and Android/Desktop development practices:
- **Kotlin Multiplatform (JVM Target)**: Shared logic module (`:shared`) and desktop runner (`:desktopApp`).
- **Compose Multiplatform Desktop**: Modern declarative UI framework powered by Skia.
- **MVVM Design Pattern**: Reactive UI state management using Kotlin Coroutines and StateFlow/MutableState.

## 🚀 Building & Running

### Running the App Locally
```bash
./gradlew :desktopApp:run
```

### Packaging Windows Executables

- **Build Portable Application Package**:
  ```bash
  ./gradlew :desktopApp:createDistributable
  ```
  *Output:* `desktopApp/build/compose/binaries/main/app/Grem/Grem.exe`

- **Build Windows `.exe` Installer Package**:
  ```bash
  ./gradlew :desktopApp:packageExe
  ```
  *Output:* `desktopApp/build/compose/binaries/main/exe/Grem-1.0.0.exe`
